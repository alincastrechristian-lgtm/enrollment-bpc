# Certificate of Registration example

[Download the example COR PDF](certificate-of-registration.pdf).

This example uses fictional student details and is clearly marked **NOT VALID FOR REGISTRATION**. It includes birth date, sex, program name and code, enrollment information, registered subjects, and total units. Fee details, grades, signatures, and seals are omitted.

Generated with the same PDF renderer used by the website. Regenerate from the repository root:

```sh
pnpm exec tsx scripts/generate-cor-example.ts
```
